# Курс «Латте-арт»

- Статус: локальный preview и Tilda-пакет подготовлены, но не опубликованы.
- Исходная Tilda-страница: `20386850`, путь `/latte-art`.
- Дата снимка исходника: 2026-08-21 (read-only Tilda API).
- Стоимость: один участник — 24 000 ₽, два участника — 32 000 ₽.
- Предоплата: 5 000 ₽.
- Программа: 3 последовательных занятия по 3 часа.

## Граница local preview

`index.html` и `preview.js` не содержат реальный booking API, оплату или
создание визитов в yClients. Модальное окно в preview — только демонстрация.
Настоящий popup вынесен в `tilda-blocks/09-online-booking-popup.html` и
подключает общий виджет только после клика пользователя.

## Production-контур, подготовленный к review

1. `schedule-online/basic-barista-booking/courses/latte-art.json` описывает
   manager-flow, три последовательных занятия, варианты для одного и двух
   участников, предоплату 5 000 ₽ и 16-часовое ограничение срочной записи.
2. Для одного участника используются услуги yClients: `20818422`, `20818425`,
   `20818428`; для двух: `20818404`, `20818410`, `20818416`.
3. Popup передаёт только slug `latte-art` общему
   `course-booking-widget.js`; ни токенов, ни API yClients в Tilda-блоке нет.
4. `latte-art` — новый индивидуальный курс. Он не связан с существующим
   `latte-art-battle`: тот slug обслуживает отдельный чемпионат и group
   activity. `trainers/overrides.json` содержит только данные профилей
   тренеров, не маршрутизацию курсов, поэтому его схема намеренно не менялась.

До release нужно выполнить независимый C-review, затем только по явному
решению Романа отдельно выложить booking-конфиг и вручную опубликовать
Tilda-блоки.
