# Tilda-блоки: «Сенсорный анализ кофе»

Пакет подготовлен для ручной вставки Романом. Его наличие не означает
публикацию страницы.

## Что заменить на странице `/sence`

Удалить или отключить только старые контентные блоки курса:

- hero и старый блок «Кому подойдёт» (`rec1194378711`, `rec1194438111`);
- старую программу и блок навыков (`rec503551877`, `rec503551878`, `rec629021178`);
- старый ценовой блок с неверными ссылками на «Продвинутый курс» (`rec2027898501`, `rec2027898851`).

Сохранить системные header/footer, форму заявки Tilda и существующий отдельный
блок тренеров (`rec2277548501`). Он уже загружает общий trainers-widget и не
должен быть продублирован.

## Порядок вставки

1. SEO-настройки страницы не менять: у `/sence` уже есть собственные Title,
   description, Open Graph и canonical.
2. Первым HTML-блоком вставить `01-hero-and-for-whom.html`.
3. Сразу после него оставить существующий блок тренеров.
4. Следующим HTML-блоком вставить `02-course-content.html`.
5. После контентных CTA вставить один раз `09-online-booking-popup.html`.
6. Последним HTML-блоком вставить `10-page-interactions.html`.

`01`, `02`, `09` и `10` создаются локально командой:

```bash
node sensory-analysis/scripts/build-tilda-blocks.js
```

## Границы CTA

- «Записаться онлайн» и «Онлайн запись» открывают popup и передают общему
  виджету только slug `sensory-analysis`;
- «Оставить заявку» всегда использует `href="#consalt"`;
- не создавать на странице реальный элемент с `id="consalt"`;
- Telegram, WhatsApp и телефон остаются отдельными контактами;
- в пакете нет кнопки предоплаты, рассрочки, `#tinkoff1`, `#tinkoff2` и
  ссылок `/prepay#order:...`.

Перед ручной публикацией нужны финальный C-review, safe `check_only` для
обоих вариантов и отдельное решение Романа «выкладывай».
