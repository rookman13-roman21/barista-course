# Профессиональный курс бариста — local preview

Локальная версия будущего обновления страницы `/expert`. Она используется
только для визуальной проверки и не создаёт визитов, броней или платежей.

## Запуск

Из корня `barista-course`:

```bash
python3 -m http.server 3216
```

Открыть `http://localhost:3216/professional-barista/`.

## Граница preview

- `preview.js` не содержит `fetch`, URL booking API, yClients, оплату или
  отправку формы;
- кнопка «Записаться онлайн» открывает только демонстрационный wizard;
- CTA «Оставить заявку» использует штатный `href="#consalt"`; локальный сервер
  не открывает Tilda popup.

После подтверждения Романа будут собраны отдельные Tilda-блоки, подготовлена
production popup-обвязка и отдельный C-пакет конфигурации записи.
