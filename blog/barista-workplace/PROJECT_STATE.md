# PROJECT STATE — Удобное рабочее место бариста

## Паспорт

| Поле | Значение |
|---|---|
| Рабочий URL | `/blog/barista-workplace` |
| Production URL | Не опубликована |
| Локальный preview | `blog/barista-workplace/index.html` |
| Tilda-артефакт | `blog/barista-workplace/tilda-block.html` — один T123 HTML-блок |
| Тип | Статичная SEO-статья без hosted loader и backend |
| Аудитория | Бариста — для быстрой проверки зоны; владельцы и управляющие — для решения о проектировании |

## Что подготовлено

- Структура с редакторским черновиком по диктовке Романа: hero с 3D-обложкой и прямым доступом к материалу, вводный блок о коммуникациях и маршруте бариста, чек-лист из шести инженерных и эргономических параметров, один ненавязчивый блок услуги, FAQ и финальная CTA.
- Ссылки на учебный 3D-проект открываются в новой вкладке с `noopener noreferrer`; iframe намеренно не используется.
- Блок услуги ведёт к существующему разделу кейсов и к странице проектирования бара.
- Локальный preview и Tilda-блок генерируются из одних `src/`-файлов, чтобы дальнейшая диктовка текстов не разошлась между ними.

## Не включать

- Формы, аналитику, данные yClients, Битрикс, API, backend и hosted loader.
- Прямые ссылки на отдельные документы вне учебного Viewer.
- Обещание, что учебный пример можно использовать как готовый проект для любого помещения.

## Статус

Структура и редакторский черновик по диктовке Романа локально подготовлены. SEO-поля и alt-текст обложки временные и требуют утверждения Романа до публикации.

До публикации также нужна отдельная управляемая проверка отзыва тестовой presentation share-ссылки Viewer: после revoke ожидается `404`; учебный проект статьи при этом не менять.
