# Удобное рабочее место бариста

Черновик второй публичной статьи раздела «Блог» Московской школы бариста.

Страница помогает бариста оценить свою рабочую зону по короткому чек-листу, а владельцу или управляющему — понять, когда для бара нужен индивидуальный проект. Центральный учебный материал — открытый 3D-проект с размерами и документами.

## Файлы

- `src/markup.html` — единственный источник структуры и рабочего текста.
- `src/styles.css` — стили с префиксом `mbs-workplace__`.
- `src/preview-template.html` — полная HTML-обёртка локального preview.
- `scripts/build.mjs` — собирает два результата ниже.
- `index.html` — локальный preview; не вставлять в Tilda.
- `tilda-block.html` — единственный HTML-блок Tilda для страницы.

## Локальная работа

```bash
node scripts/build.mjs
node tests/structure.test.mjs
```

После сборки открыть `index.html` через локальный HTTP-сервер. Любая редакторская правка вносится сначала в `src/`, затем оба выходных файла пересобираются.

## Публикация

Страница статична: hosted loader, API, форма, аналитика и внешние runtime-запросы не нужны. В Tilda вставляется целиком только `tilda-block.html` в один T123 HTML-блок.

Перед публикацией:

1. заменить временные тексты, Title, Description, Canonical и alt-текст обложки на утверждённые;
2. убедиться, что Tilda не добавляет второй H1;
3. проверить desktop, 390 и 360 px, CTA на учебный проект, ссылку «Посмотреть кейсы» и страницу услуги;
4. отдельно подтвердить на тестовой публикации Viewer, что отозванная share-ссылка отвечает `404`. Учебный материал для статьи во время этой проверки не отзывать.

Публикация в Tilda и production-проверка выполняются только после отдельного подтверждения Романа.
