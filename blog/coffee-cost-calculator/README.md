# Калькулятор себестоимости кофейных напитков

Первый публичный учебный материал будущего раздела «Блог» Московской школы бариста.

## Что считает

Калькулятор показывает прямую себестоимость одной порции: ингредиенты и упаковку. Пользователь выбирает один из 12 базовых напитков, меняет цену и размер нужной упаковки и сразу видит разбивку суммы.

Результат не включает аренду, зарплату, налоги, доставку и другие операционные расходы.

## Путь между учебным материалом и сервисом

Статья и калькулятор — полезный первый шаг для человека, который пока выбирает, нужен ли ему полный сервис MBS* Coffee Menu. В hero страницы `/open_cafe_app` размещена спокойная ссылка на `/blog/coffee-cost-calculator`; CTA для владельца на странице калькулятора возвращает на `/open_cafe_app`.

Этот маршрут не меняет стоимость, покупку или заявку сервиса и не должен превращаться в агрессивный дополнительный CTA.

- Источник: `Coffee_menu/HTML_coffee_menu/src/data/drinks.js` и `src/data/mat.js`.
- Зафиксированный commit: `1439df3527214f1190ccfb955b40b292c08719bb`.
- Данные открыты только для 12 базовых учебных рецептур; поставщики, процессы приготовления, видео, авторские и платные рецептуры сюда не переносятся.

Перед обновлением снимка сверить его с Coffee Menu, изменить SHA и дату в `src/data.js` и `PROJECT_STATE.md`, затем выполнить проверки ниже.

## Локальная работа

```bash
node scripts/build.mjs
node tests/calc.test.mjs
node tests/structure.test.mjs
```

`index.html` — локальный preview всей будущей страницы. Сборка также создаёт:

- `hosted/coffee-cost-calculator.html` — интерактивный калькулятор для сервера;
- `tilda-seo-block.html` — статичный H1, статья, FAQ и CTA для первого HTML-блока Tilda;
- `tilda-loader.html` — код калькулятора для второго HTML-блока Tilda;
- `tilda-block.html` — полный локальный архив страницы. Его не вставлять в Tilda.

В Tilda вставляются ровно два подготовленных файла в таком порядке: сначала `tilda-seo-block.html`, затем `tilda-loader.html`. Первый файл оставляет H1 и статью в исходном HTML страницы, поэтому они доступны поисковым роботам без JavaScript. Loader подгружает только интерактивный калькулятор и автоматически ставит его между первым экраном и статьёй.
