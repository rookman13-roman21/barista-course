# Калькулятор себестоимости кофейных напитков

Первый публичный учебный материал будущего раздела «Блог» Московской школы бариста.

## Что считает

Калькулятор показывает прямую себестоимость одной порции: ингредиенты и упаковку. Пользователь выбирает один из 12 базовых напитков, меняет цену и размер нужной упаковки и сразу видит разбивку суммы.

Результат не включает аренду, зарплату, налоги, доставку и другие операционные расходы.

## Источник данных

Публичный снимок рецептур находится в `src/data.js`.

- Источник: `Coffee_menu/HTML_coffee_menu/src/data/drinks.js` и `src/data/mat.js`.
- Зафиксированный commit: `1439df3527214f1190ccfb955b40b292c08719bb`.
- Данные открыты только для 12 базовых учебных рецептур; поставщики, процессы приготовления, видео, авторские и платные рецептуры сюда не переносятся.

Перед обновлением снимка сверить его с Coffee Menu, изменить SHA и дату в `src/data.js` и `PROJECT_STATE.md`, затем выполнить проверки ниже.

## Локальная работа

```bash
node scripts/build.mjs
node tests/calc.test.mjs
node tests/structure.test.mjs
```

`index.html` — локальный preview. `tilda-block.html` создаётся из тех же исходников и вставляется в один HTML-блок Tilda.

## Граница публикации

Код и Tilda-блок можно подготовить локально. Вставка, создание попапа `#consalt` и публикация требуют отдельного разрешения, независимого review и проверки на опубликованной странице.
