# PROJECT STATE — Калькулятор себестоимости кофейных напитков

| Поле | Значение |
|---|---|

| Локальное превью | `blog/coffee-cost-calculator/index.html` |
| Tilda-артефакты | `blog/coffee-cost-calculator/tilda-seo-block.html` + `blog/coffee-cost-calculator/tilda-loader.html` |

| Сохранение | Только `localStorage`: `mbsCostCalc:v1:prices`, `mbsCostCalc:v1:selection`. Цена ингредиента общая для всех напитков, в которых он используется. |

## Что подготовлено

- Mobile-first калькулятор себестоимости продуктов и упаковки без регистрации. В локальном preview сетевых запросов нет; Tilda loader при публикации загрузит серверный HTML калькулятора.
- Открытые нормы: эспрессо доппио, американо 200, капучино 200/300, латте 300/400, флэт уайт, раф ванильный, какао 300, матча 300, айс-латте 300, фильтр-кофе 300.
- Формула совпадает с Coffee Menu: `(цена упаковки / размер упаковки) × расход`; поле `loss` поддерживается как `/ (1 − loss)` для будущего расширения базы.
- Внутри страницы: методика расчёта, границы результата, FAQ, CTA на `/open_cafe_app` и `#consalt`.

## Что не включать

- Поставщиков, процессы приготовления, видео, цену продажи, авторские рецептуры, CRM/yClients/Bitrix-данные и пользовательские расчёты.
- API, backend, `.env`, аналитику и любые внешние запросы из самого hosted-калькулятора. Единственный внешний запрос будущей Tilda-страницы — loader к публичному статическому HTML на `api.barista-school.ru`.
- Видимый элемент с `id="consalt"`: он перекроет штатный Tilda-попап.

## Как проверить

1. Выполнить `node scripts/build.mjs`, затем оба теста из `tests/`.
2. Открыть `index.html` и проверить 360 и 390 px: выбор напитка, изменение цен, сброс, FAQ, обе CTA и работу с клавиатурой.
3. Перед Tilda проверить, что `hosted/coffee-cost-calculator.html` содержит маркер `data-mbs-costcalc-hosted="v1"`, не содержит H1 и не содержит приватных данных; `tilda-loader.html` содержит только один публичный URL сервера, timeout, проверку ответа и fallback.
4. После отдельного разрешения на публикацию вставить в Tilda сначала `tilda-seo-block.html`, затем `tilda-loader.html`; создать попап заявки, выложить hosted-файл на сервер, затем проверить `#consalt`, `/open_cafe_app`, опубликованный URL и мобильный сценарий.
