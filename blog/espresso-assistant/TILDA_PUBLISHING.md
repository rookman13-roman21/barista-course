# Публикация `/blog/espresso-assistant`

Публикация выполняется вручную Романом после merge и отдельного разрешения на hosted deploy.

## SEO-поля Tilda

| Поле | Значение |
|---|---|
| URL | `blog/espresso-assistant` |
| Title | `Помощник настройки эспрессо \| Московская школа бариста` |
| Description | `Запишите дозировку, выход, время и вкус эспрессо. Помощник рассчитает коэффициент выхода, сохранит попытки и подскажет одно изменение для следующего шота.` |
| Canonical | `https://baristaschool.ru/blog/espresso-assistant` |

JSON-LD уже находится в `tilda-seo-block.html` и не должен дублироваться в loader или hosted-файле.

## Порядок выпуска

1. Убедиться, что готовый код смержен и локальный `main` совпадает с `origin/main`.
2. Сохранить текущий серверный файл, если endpoint уже существует.
3. Выложить `hosted/espresso-assistant.html` как `/var/www/html/api/espresso-assistant.html` штатным способом сервера.
4. Проверить HTTPS, CORS, `no-store`, `X-Robots-Tag: noindex, follow` и маркер `data-mbs-espresso-assistant-hosted="v1"`.
5. Создать в Tilda страницу с URL `/blog/espresso-assistant`.
6. Вставить в первый T123 HTML-блок полное содержимое `tilda-seo-block.html`.
7. Сразу после него вставить во второй T123 HTML-блок полное содержимое `tilda-loader.html`.
8. Заполнить SEO-поля из таблицы и опубликовать страницу.

`tilda-block.html` не вставлять: это локальный полный архив.

## Live-приёмка

- в исходном HTML страницы ровно один H1;
- статично присутствуют методика, FAQ, CTA и три типа JSON-LD;
- loader загружает проверенный hosted-файл и ставит его между Hero и методикой;
- создание сессии и запись попытки работают после перезагрузки;
- несбалансированный шот `<25 с` получает только рекомендацию сделать помол мельче;
- несбалансированный шот `>30 с` получает только рекомендацию сделать помол крупнее;
- сбалансированный шот в диапазоне `20–35 с` обходит советный временной гейт;
- два близких сбалансированных шота, включая два шота по 23 секунды, подтверждают повторяемость;
- CTA ведёт на `/barista_courses`;
- на 360 и 390 px нет горизонтального переполнения, кнопки и поля доступны касанием;
- при недоступном hosted endpoint остаются статичная методика, fallback и CTA.

## Откат

- вернуть сохранённый hosted-файл;
- восстановить предыдущие сохранённые версии двух Tilda-блоков и заново опубликовать страницу;
- повторно проверить живой URL, а не только ответ endpoint.
